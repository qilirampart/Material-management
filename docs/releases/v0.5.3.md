# v0.5.3 独立文件清理模块

## 下载和升级

- Windows 推荐完整安装包 **DianzhongMaterialAssistant-Setup-0.5.3.exe**，无需另装 Python 或 FFmpeg。
- 访问 GitHub、检查更新和下载更新前请开启 VPN。旧版本可在“设置 → 软件更新”检查更新；下载失败时可直接下载完整安装包。
- 升级前结束任务并关闭旧软件，直接覆盖安装；不必卸载，不要删除素材保存目录、历史批次或配置。
- macOS 提供未签名构建包，尚无真实设备验收。

## 新增“06 文件清理”

在“素材再创作”顶部，进入自动上传之后的 **06 文件清理**。

1. 浏览素材保存目录；文件列表显示名称、大小、类型和修改时间。修改保存目录后，清理页同步切换。
2. 选中文件或文件夹（Ctrl / Shift 多选），点击 **预览所选范围**。
3. 核对清单后点击 **确认删除清单中的文件…**，再次确认后执行。

可清理软件登记的下载原片、加工成品及配套封面，以及批次内上传暂存视频。选择封面时，其对应成品会一同列入清单。文件删除不经过回收站；大小为逻辑合计，不代表实际释放空间。

批次记录、配置、外部导入原文件及未登记文件可以查看，但不会被删除；文件夹本身保留。记录已丢失的批次可继续使用下载页“清理勾选批次…”中的“仅移出批次列表”整理。

## 删除后立即同步

- 下载原片清理后恢复待下载状态，并移除对应的 MD5 / 微创新加工来源。
- 成品清理后移出待上传列表；清空本地待上传准备，不改动智投网页中尚未提交的表单。
- 仅清理一条原片时，同批次其他下载队列条目保留。
- 任务运行期间不能清理。预览后记录或文件发生变化会拒绝旧清单；占用或权限问题会显示未完成项目。

已完成本地目录浏览、选择预览、删除与各模块联动检查，以及全量回归测试。Windows 发布流程还执行安装包对应程序的内置浏览器、FFmpeg、加工、播放和清理检查。跨平台测试与构建结果见本版本 GitHub Actions。
