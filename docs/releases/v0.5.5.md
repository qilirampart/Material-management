# v0.5.5 历史文件清理与操作指引

## 清理页操作

进入 **素材再创作 → 06 文件清理**：

1. **选择范围**：选中文件夹或具体视频文件；支持 Ctrl / Shift 多选。
2. **预览清单**：点击“预览待删除文件”，核对文件名、数量、大小。
3. **确认删除**：预览后有可删除文件时，删除按钮才会启用；核对后点击并再次确认。

仅清理软件可确认归属的 **MP4 视频及配套封面**。文档、配置、批次记录、外部导入原文件和无法确认归属的文件不会删除，文件夹本身保留。选择封面时，对应成品会一同列入清单。删除不经过回收站。

## 修复和改进

- 历史文件不必加入当前处理或工作区列表即可清理，直接从所选文件或文件夹识别磁盘批次记录。
- 修复历史原片存在、清单却显示 0 个文件，导致删除按钮不可用的问题。
- 切换选择后立即清空旧清单；页面增加三步说明及明确的下一步提示。
- 清理后立即同步下载、MD5 / 微创新来源及待上传列表，保留其他任务。

## 下载升级

Windows 推荐 **DianzhongMaterialAssistant-Setup-0.5.5.exe**。访问 GitHub、检查更新和下载前请开启 VPN。结束任务并关闭旧软件后覆盖安装，保留配置、素材目录和历史批次；也可在“设置 → 软件更新”升级。

macOS 提供未签名构建包，尚无真实设备验收。
