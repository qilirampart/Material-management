# v0.5.2 失效批次修复与视频清理

## 下载和更新

- Windows 推荐完整安装包 `DianzhongMaterialAssistant-Setup-0.5.2.exe`，无需另外安装 Python 或 FFmpeg。
- 访问 GitHub、检查更新和下载更新前请开启 VPN，确认能下载 Release 附件。旧版可通过“设置 → 软件更新”检查更新；若下载失败，直接下载完整安装包。
- 升级前先结束任务并关闭旧软件。不需要先卸载，不要删除素材保存目录、配置或历史批次。
- macOS 为未签名构建包，未完成真实设备验收；平台自动上传的真实验证在 Windows 上完成。

## 修复删除旧文件后不能继续处理的问题

- 一个旧批次的 `recreation.json` 缺失，不再阻塞其他批次的 MD5／微创新导入与加工；失效来源单独提示。
- 加工列表按来源标识移出视频，避免失效记录导致行号错位、移错条目。
- 下载队列可跳过不可用批次，其他批次继续；上传准备时文件消失，不再遗留忙碌状态。
- 加工时遇到批次记录不可用，会跳过或报告该批次，已生成的文件与加工记录保留。
- 素材管理页面识别兼容直接页面、同源嵌套页面和延迟菜单；页面未准备好时明确提示“尚未查询剧目”。

## 新增软件内清理

进入“素材再创作 → 02 视频下载”，左侧勾选批次后点击“清理勾选批次…”。

可选范围：
1. **仅移出批次列表**：只移除相关队列和加工引用，不删除文件。已被外部删除、显示不可用的旧批次可用此选项整理。
2. **删除加工成品与配套封面**：保留下载原片和批次记录。
3. **删除下载原片**：保留成品和批次记录，同步待下载状态、加工来源及队列。
4. **删除原片和加工成品**：保留批次记录。

操作前预览文件范围并二次确认。文件删除不经过回收站；外部导入原文件、上传暂存和批次记录保留。文件大小合计不等于实际释放空间。任务运行中不能清理，部分失败会明确反馈。
