# v0.5.2 候选版

本地 Windows 候选安装包，用于验证删除旧文件夹后不能导入加工列表的问题；尚未发布到 GitHub，不覆盖线上 v0.5.1 下载。

## 修复

- 删除旧批次记录不再阻塞其他批次的 MD5／微创新导入；失效来源单独提示，不自动删除索引或用户文件。
- 加工列表移出操作改按来源标识匹配，避免失效引用造成行号错位。
- 下载队列跳过不可用批次继续；上传准备时文件消失会释放忙碌状态并明确提示。
- 加工期间记录失效不会阻断后续独立批次；已生成的文件与加工记录保留。
- 智投素材管理页面识别兼容直接页面、嵌套页面和延迟加载菜单；需要用户已登录现场复测查询。

## 使用清理入口

进入“素材再创作 → 02 视频下载”，在左侧勾选批次，点击“清理勾选批次…”。

1. 仅移出批次列表：只移除相关队列与加工来源引用，不删任何文件。适合处理已在外部删掉、现在显示不可用的旧批次。
2. 删除加工成品与封面：保留下载原片与批次记录。
3. 删除下载原片：保留加工成品与批次记录，下载记录恢复待下载，加工来源与下载队列同步。
4. 删除原片和加工成品：保留批次记录。

先查看文件范围和数量，再二次确认。删除不经过回收站；外部导入原文件、上传暂存和批次记录保留。文件大小合计不等于实际释放空间。运行中不能清理，部分失败会保留相关记录并显示详情。

## 更新注意

结束当前任务并退出旧软件后运行候选安装包。不需要先卸载，不要删除素材保存目录、配置或历史批次。升级后正常批次应可直接继续，失效批次按上面的“仅移出批次列表”处理。
