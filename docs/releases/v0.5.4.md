# v0.5.4 历史文件清理修复

## 修复

- “06 文件清理”不再依赖当前工作区或处理列表。选中历史文件时直接读取其所属批次记录；选中父目录时查找其中的历史批次。
- 修复历史原片明明存在、预览却为 0 个文件，导致删除按钮不可用的问题。
- 改变文件选择后立即清空旧预览，避免清单与当前选择不一致。
- 删除后继续同步对应下载、加工及待上传状态。批次记录、配置、外部原文件和无法确认归属的文件仍受保护。

## 使用

进入 **素材再创作 → 06 文件清理**，选择文件或文件夹，点击 **预览所选范围**，核对后确认删除。无需先打开历史批次，也无需把文件导入 MD5 或微创新列表。删除不经过回收站。

Windows 推荐 **DianzhongMaterialAssistant-Setup-0.5.4.exe**。访问 GitHub、检查更新和下载前请开启 VPN。先结束任务并关闭旧软件，再覆盖安装；保留素材目录、配置和历史批次。旧版也可通过“设置 → 软件更新”升级。

macOS 提供未签名构建包，尚无真实设备验收。

## 验证

已复现并修复“历史批次未在当前列表中”的情况；对反馈中的真实原片完成只读预览验证，清单识别出 1 个文件、105076583 字节，未删除该文件。新增历史单文件、父目录多批次、未知文件保护和界面状态回归测试；Windows 打包后检查同步覆盖历史文件清理接口。
