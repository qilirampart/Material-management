# v0.5.1 发布记录

## 发布前阻塞与修复

- v0.5.0 标签构建 `43807317061` 被测试门禁阻止，未生成正式 Release。保留原标签与失败记录，不改写标签；修复版使用 v0.5.1。
- FFmpeg 9.0.2 本地复现：极小区域模糊半径不得等于短边的一半；修正旧遮罩和区域效果的半径边界。
- 片头静止画面切入运动画面的短预览使用两秒 VBV 缓冲时，平均视频码率达到约 6.3 Mbps；短片改用半秒缓冲。最终码率和大小检查保持不变。
- macOS 普通 Homebrew FFmpeg 已不包含字幕滤镜；测试和打包改用 `ffmpeg-full`，并将其 bin 放入 PATH。参考：https://formulae.brew.sh/formula/ffmpeg-full 。
- macOS 字体查找补充 Songti／STHeiti／Helvetica；路径测试比较规范化后的路径，兼容 Windows 临时路径大小写及 macOS `/private` 链接。
