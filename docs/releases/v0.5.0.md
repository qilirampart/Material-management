# v0.5.0 · 素材再创作与资源管理优化

## 下载与安装

- **Windows 推荐完整安装包**：`DianzhongMaterialAssistant-Setup-0.5.0.exe`，无需另装 Python 或 FFmpeg。
- `Downloader` 是在线下载器，运行后仍需联网下载完整包；网络不稳定时直接使用完整安装包。
- macOS 提供未签名构建包，尚未完成真实设备验收。平台上传在 Windows 上完成了实际验证。

## 新增素材再创作流程

- 登录点众智投 → 分批下载 → 改 MD5 → 微创新 → 自动上传；与原素材任务分开操作，共用智投登录态。
- 支持多剧目批次、分页采集、勾选与反选、按剧归档、停止与恢复；新批次默认排除名称含“小方块”的素材，不限制正常横版。
- 改 MD5 保留原音画并生成独立副本；微创新支持画面与调色、速度、动态构图、背景／画中画、文字、水印、配乐、片头尾、字幕、封面及同片分屏。
- 支持效果预览、全屏播放、命名收藏、多版本生成及方案导入导出。
- 成品按剧目准备上传，停在最终提交前；已有未提交表单不会被自动覆盖。

## 稳定性与资源占用

- 两套流程的重任务互斥，后台任务结束后释放对象及捕获数据；下载并发仍默认 1、最多 3，转码任务串行。
- 为 FFmpeg 的编解码与滤镜组设置最多 4 的内部线程预算，低核机器相应降低。
- 大批次来源索引与增量刷新，保留勾选和滚动位置。
- 加工前估算磁盘占用，余量不足时停止剩余处理、保留已完成结果；保存目录对新批次即时生效。
- 补齐元数据探测取消、上传页组件加载等待；参数框滚轮只滚动页面，避免误改设置。
- 支持从有效加工记录找回已落盘但未登记的成品。

## 使用要点

- 微创新成品继续校验视频码率 **>3500 且 ≤5000 kbps**、单文件 **≤510 MiB**；仅改 MD5 不会压缩或提升原片码率。
- MD5 改变不等于平台一定认定为新素材。精彩剧情筛选仍由人工完成，专用模型 API 尚未接入。
- Windows 本地已完成两剧下载、加工和上传验证，均未提交；完整安装包已通过独立安装及运行验收。
