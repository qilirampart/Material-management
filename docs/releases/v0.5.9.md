# 点众素材投放助手 v0.5.9

- **智投名称筛选**：视频下载页可按批次设置名称包含、名称排除，重开批次后仍保留。
- **改 MD5 提速**：在「设置 → 任务与存储」可选双路，并单独允许与单路抖音纯下载同时运行。默认仍用单路、不同时运行；下载时建议选单路，机器资源不足时不会强开。
- **任务提醒**：在左侧查看整轮结果或需要处理的事项。离开任务页时可显示系统通知；自动上传正常换批不逐批打扰。下载失败会显示失败条数和重试入口。

Windows 推荐使用完整安装包，无需另装 Python 或 FFmpeg。已安装旧版可从「设置 → 软件更新」检查。无法访问 GitHub 的同事可使用同事转发的完整安装包。

验收范围和复验方法见 [并发与任务提醒验收](../并发与任务提醒验收.md)。
