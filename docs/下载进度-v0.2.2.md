# 下载进度 v0.2.2

将下载器原有字节回调接入独立 worker 的事件文件，再传到桌面界面。后台任务卡显示当前流的已下载量、总大小、百分比和平均速度；候选表下载列同步显示进度。窗口较窄收起侧栏时，列表和底部状态栏仍可查看进度。

总大小未知时使用活动进度条，显示实际已下载量，不生成百分比或剩余时间。重试或开始新的媒体流时重置计数；视频与音轨分别计量，100% 只代表当前流传输完成。解析、本地校验、保存、抽帧和模型识别显示各自阶段。

字节事件约每 300ms 发一次，已知长度传输完成时立即发出；界面只更新当前行，避免每个数据块重建整张表。进度事件不包含媒体地址或密钥。

验证：23 项单元测试通过，包含节流、速度、完成、重试重置和未知大小；scripts/verify_download_ui.py 验证实际 Qt 窗口从事件文件读取进度、显示大小与百分比、未知长度和校验阶段切换。output/download_progress_test/download-progress.png 使用模拟事件展示布局，不是真实网络下载截图。本轮未额外下载线上视频。
