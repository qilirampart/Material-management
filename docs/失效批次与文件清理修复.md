# 失效批次与文件清理修复

## 目标

删除旧批次或视频后，其他有效批次仍可下载、导入、加工与准备上传。提供软件内的批次清理入口，明确区分移出记录、删除下载原片、删除加工成品；操作前确认，不删除外部导入的用户原文件。

## 验收任务

- [x] 加工来源逐批解析；失效记录可见但不堵住有效视频，移出操作按来源标识而非错位行号执行。
- [x] 队列遇到缺失批次可跳过并说明；刷新期间的文件变化不遗留禁用信号或旧列表。
- [x] 批次清理支持预览范围与二次确认，运行中禁止；只删除批次内登记的视频和配套封面，不递归删目录，不跟随链接删除外部文件。
- [x] 删除成功、部分失败、记录保存失败有明确反馈；原片、成品、下载队列与两套加工输入同步；上传前再次检查文件。
- [x] 回归覆盖外部删除、多个批次混用、外部视频保护、重复清理及失败恢复；渲染实际清理界面。
- [x] 构建 v0.5.2 本地候选安装包并验证；不改写已发布 v0.5.1，不自动执行真实用户文件清理。
