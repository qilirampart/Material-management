# 文件清理模块

目标：作为再创作流程第 6 步，浏览素材保存目录中的文件；通过软件删除后立即同步下载、加工来源、成品及待上传列表。

## 范围与验收
- [x] 目录树按需加载，显示所有文件、大小、修改日期；根目录跟随素材保存设置。
- [x] 选中文件或目录后预览具体删除清单；仅删除可确认归属的下载原片、加工成品/封面和上传暂存视频。
- [x] 批次记录、配置、外部导入原文件及未登记文件保持可见但保护；不递归删除目录。
- [x] 删除前二次确认，任务运行时禁用；文件或记录变化后拒绝旧预览。
- [x] 完成后立即刷新各流程状态，清理锁定失败准确反馈。
- [x] 单测、跨模块联动及实际 UI 渲染验收。

v0.5.2 已完成发布，本模块不改变该标签和发布产物。

## 本地验收

- 选择一个原片，只删除该原片、同步两个加工来源列表；同批次其他下载队列条目保留。
- 选择单个成品或其封面，清单同时列出成品与封面，删除后移出上传成品库。
- 上传暂存视频可单独清理，原片、成品、历史上传记录保留；待上传准备在本地清空，网页表单不改动。
- 外部导入视频、记录和未登记文件不纳入删除；锁定、文件变化、保存失败沿用已有错误处理。
- UI 与联动证据：`output/file-cleanup-acceptance/preview.png`、`after-cleanup.png`、`result.json`。测试媒体位于自动销毁的临时目录，未删除业务文件。
- 新增选择清理与页面联动测试 9 项；清理相关合计运行 18 项，17 项通过，1 项因 Windows 无符号链接权限而跳过。
- 全量回归运行 352 项，351 项通过、1 项跳过；最终一轮日志：`tmp/file-cleanup-diagnostic-regression.log`。目录标题/切页刷新及队列局部保留另有定向验证，流程相关 20 项通过（`tmp/file-cleanup-final-affected.log`）。

下载页原有“清理勾选批次”入口继续保留，便于按批次清理或移出失效批次。
