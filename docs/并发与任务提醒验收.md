# 并发与任务提醒验收

范围：素材助手的双路改 MD5、单路抖音纯下载和改 MD5 的重叠运行、任务提醒。验收使用隔离目录，不改动正式批次，不上传或提交。

| 验收项 | 结果 |
| --- | --- |
| 下载中开启双路改 MD5 | 弹窗默认本轮用单路；可选双路。资源不足时拒绝启动不安全的组合。 |
| 实际下载进程与改 MD5 重叠 | 用本机 HTTP 服务提供合成 MP4。两条改 MD5 成品在真实下载进程仍运行时入库；下载放行后正常保存。三个文件均通过视频完整性检查。 |
| 抖音联机验收 | 通过正式 Excel 输入和下载链路下载一条 [公开风景视频](https://www.douyin.com/video/7708524681044915546)（304.77 秒）。两条本地改 MD5 成品在下载进行中先入库；下载完成后，文件、结果记录和 Excel 报表均正常。 |
| 改 MD5 后启动抖音纯下载 | 用测试核对请求：下载错峰用单路，不覆盖设置；正在处理的素材不停止，下载结束后恢复双路。下载加检测仍互斥。 |
| 任务提醒频率与跳转 | 前台只记录结果，离开任务页后合并相邻提醒，并优先显示需要接手的事项。自动上传连续两批只发一条结束提醒；应用内点击能跳转任务页。 |
| 单条失败、进程正常退出 | 验收发现原本只报普通结束；已修复为显示本轮下载失败条数，可在素材任务页重试。历史批次失败不计入本轮提醒。 |
| Windows 系统通知 | 已在真实 Windows 窗口验证最小化后调用系统托盘通知。系统横幅是否实际弹出、点击横幅是否回到对应任务页，未单独观察确认。 |

全量回归：运行 412 项，411 项通过，1 项跳过。跳过项为清理模块的符号链接测试，本机未授予创建链接的权限，与本次并发及提醒无关。

本地复验：`python scripts/verify_speed_acceptance.py`。该脚本生成合成视频，运行真实下载子进程和加工流程；视频随临时目录清理。加 `--native` 可在 Windows 桌面观察系统提醒。
