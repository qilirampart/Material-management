## 安装包验收规则

- 只打完整 Windows 安装包，避免候选版本尚未公开时在线下载器找不到资源。
- 安装验证使用独立 AppId 的测试包和工作区内测试目录，防止改写已安装正式软件的卸载注册信息；供试用的候选包仍使用正式 AppId。
- 构建内容只带示例配置、参考图和运行库，不带账号、浏览器数据、模型配置或开发机运行目录。
- 两剧测试上传均停在提交前；按用户明确授权取消并清空验收表单，不保存草稿、不提交。macOS 真实设备验收不在本机冒充完成。
