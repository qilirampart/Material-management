## 采用的交互

- Excel、抖音分享链接、本地视频均先进入候选素材区；默认不勾选、不自动处理。
- 勾选素材后选择仅下载、仅检测、下载并检测。仅检测缺少本地文件时提示，不补下载。
- 模型配置提供名称、API 地址、模型名称和密码遮挡的 API Key，支持测试连接和保存。
- 后台任务区显示运行数、并发上限及暂停入口；任务执行与界面线程分离。
- 复核展示真实首帧及 1 秒、2 秒的证据，命中项标注；未命中只能说明片头抽检未发现。
- 平台工作台保留入口，后期内置浏览器供用户登录，再逐步对齐上传功能。

## 落地时需修正的示意细节

- 图中后台区以两个不同批次演示任务状态；首期软件可先限制同一批次内的任务并发，不能据此宣称跨批次调度已实现。
- 只有下载接口提供可靠字节进度时才显示百分比；没有可靠依据时显示阶段和耗时，不编造剩余时间。
- 图中命中证据仅作排版示意，真实界面必须展示实际命中字样所在的视频帧。
- 模型配置在实际软件中由按钮打开独立对话框，参考图叠放是为了同时展示布局。
- 缩窄窗口时，证据面板移到独立复核页，保证勾选表格和三个操作模式可用。
