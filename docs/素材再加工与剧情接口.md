# 素材再加工与剧情接口

## 五个独立页面（已接入正式工作区）

用户于 2026-11-12 确认预览并授权改造。主窗口现使用 `src.recreation_workflow.RecreationWorkflowPage`；原素材任务和原平台工作台保持各自入口。最初独立预览仍保留在 `prototypes/recreation_flow_preview.py`，它不是正式运行入口。

顶部入口：**登录点众智投 → 视频下载 → 改 MD5 / 微创新 → 自动上传**。改 MD5 与微创新是两个独立处理分支，不要求先后都执行。

- 登录页：直接使用现有 `PlatformPage` 的浏览器区域；采集和上传调用同一组件、同一页面和共用 Qt 登录会话，不另建登录页或导出凭据。
- 下载页：左侧独立批次列表、批量导入剧目 ID、导入批次文件和多批次下载队列；右侧显示当前批次素材，支持勾选、全选、反选、数量统计、下载及分别导入两个处理模块。新导入每部剧建立独立批次；历史多剧批次保留原结构，不迁移或删改文件。
- 改 MD5：左侧待处理视频列表，右侧仅保留 MD5、数量和命名设置；有下载批次及本地视频两种导入入口。处理结果保存回来源批次。
- 微创新：左侧视频列表，右侧按画面／调色／时间／水印／音频／区域／叠加／多版／头尾九类配置；样片及批量处理按钮保持可见，小屏参数区滚动；沿用真实 FFmpeg 处理，不再弹出混合模式窗口。
- 导入未下载素材：明确确认后下载，仅把下载成功且文件存在的素材加入对应处理列表；失败、停止或缺失的本地文件不假装导入成功。两个模块各自记住导入项。
- 上传页：统一读取已登记批次的两种成品，按处理来源筛选、勾选，按批次、剧目和最多 50 条分组。自动生成暂存名称、填表、选文件、点击文件控件“上传”，等待服务器计数与成功预览一致；不保存草稿、不点击最终提交。

批次文件支持 `ID-剧名.xlsx/csv` 文件名、带“剧目ID/短剧ID”及可选“剧名”列的 XLSX/CSV 清单、已有 `recreation.json`。表格创建的是智投剧目查询批次，不把其中抖音链接冒充智投源文件地址；导入后先获取平台素材再下载。

工作区索引仍使用 `runtime/recreation-workspace.json`，兼容旧的单个 `last_batch`，增加批次列表、待处理下载队列及两个模块的导入引用。重启后恢复但不自动运行队列；点击“继续下载队列”才开始。成功上传记录追加在来源 `recreation.json` 的 `uploads`，显示“已上传（提交由平台确认）”，不冒充已提交；再次上传有确认提示。

平台当前表单已有上传文件、正在上传或存在未提交标记时，自动操作会在填表和选择文件之前停止。每批上传成功后，用户在登录页手动处理当前表单，再点击“继续下一批”。停止或关闭时不中途关闭网站正在传输的上传，等待本次上传结束，不启动后续批次。

真实本地验收目录为 `output/five-step-acceptance/`：从已保存的两剧采集清单建立独立验收批次，第一剧 171 条、第二剧 582 条，分别引用各自一条已下载原视频。新工作台实际生成一份改 MD5（227.416 秒原片，13.59 秒完成）和一份微创新（103.236 秒原片，33.73 秒完成，720×1280、4211962 bps、54884589 字节），均保存至对应来源批次并进入成品库。`result.json` 保存参数与输出元数据，五页及小屏截图位于同目录。没有覆盖原片或用户原批次。

完整 225 项测试通过，覆盖批次隔离、旧配置兼容、未下载确认与部分失败、队列暂停恢复、真实 MD5 处理、跨剧目/50 条分组连续序号、重复上传确认、路径切换与导入目标批次正确性、未提交表单保护；浏览器上传脚本还通过实际 JavaScript 执行测试验证只点击上传按钮。新控制器未再次向真实平台上传，需用户处理此前未提交表单后做一次实传验收；此前两个案例文件的真实上传证据保留。macOS 设备验收与新版本构建发布尚未进行。

## 在独立工作区生成新版本

从侧栏进入“素材再创作”。该入口独立管理剧目、来源、成品及上传准备，不读写原“素材任务”的候选区、勾选状态和历史批次。与原平台工作台共用浏览器登录会话，页面和上传配置分开。

1. 在“登录点众智投”打开平台并完成登录。在“视频下载”批量导入剧目 ID 或批次清单，选择左侧批次，点击“查询本批次素材”。默认上传日期为 2014-01-01 至今天，避免平台默认近 14 天的范围漏掉旧素材。
2. 下载本批勾选项，或勾选左侧多个已查询批次加入下载队列；成功项会跳过。列表提供全选、反选、清除选择和数量统计，行高亮不代表勾选。点击“导入改 MD5”或“导入微创新”，也可在对应模块从下载批次或本地导入；未下载项需确认下载。
3. 微创新先勾选视频、调整参数，点击“预览当前效果”：处理第一条勾选视频的短片段，在软件内播放，支持暂停和拖动；点击“全屏播放”、双击画面或按 F11 进入全屏，Esc 或 F11 退出全屏而不关闭播放器。原片预览起点可指定，默认输出 10 秒，可选 1–30 秒；起点早于去头设置时使用裁剪后起点，接近片尾时缩短到剩余时长。预览无需上传人缩写，不加入成品库或上传列表，关闭预览即清理临时文件。返回可继续调整，满意后生成完整样片或批量生成，每条可生成 1–10 个版本；完整样片会进入成品库。
4. 成品自动保存回来源批次，在“自动上传”统一显示。两个处理模块互不依赖；参数使用独立“− / +”按钮或直接输入，加工期间禁用参数。
5. 在上传页勾选成品，填写编导和上传人缩写，点击“开始上传勾选成品”。固定“客户端二组”可见，按剧自动分批；每批上传完成后到登录页人工处理当前表单，再继续下一批。

如需片头尾，在“头尾”选择图片或视频，设置使用长度和连接方式。预览按钮左侧选择“主体效果”“片头转场”或“片尾转场”：主体预览仍使用原片起点和 1–30 秒时长，不包含片头尾；片头预览是完整片头与主体开头片段，片尾预览是真实主体末段与完整片尾。转场模式的总预览时长另加对应片头／片尾并扣除重叠，不将中间截取片段冒充正式片尾。主体预览起点在转场模式禁用。

字幕与封面入口在“水印 → 字幕与封面…”。选择本地字幕文件或设置封面后点击“保留设置”，再使用主面板“预览当前效果”。看封面时将原片起点设为 0；启用片头时选择“片头转场”。同一字幕和封面设置应用到本次全部勾选视频，不自动寻找同名字幕。生成后可点“查看最近封面”打开独立图片；收藏当前格式可保存整套设置。

分屏、黑白／底片／棕褐、暗角及边框在“画面 → 分屏与画面效果…”。先保留设置，再点“预览当前效果”；“关闭本组效果”需保留设置后生效，不重置其他分类。竖屏原片做左右三屏时可选横屏 1280×720、前景 100%、单格完整显示，以减少二次缩小。所有布局均复制同一原片，不混用其他视频。

分享格式使用设置面板顶部“方案文件”：选择“导出当前参数…”并命名，保存为 `.dzmicro.json`；导出的是当前实际参数，包括尚未收藏的修改，不是下拉框中收藏的旧值。接收方选“导入到收藏…”，核对方案和引用资源，默认同名另存一份，也可明确选择替换同名收藏。导入不切换正在编辑的参数，从收藏列表选中后才应用。文件保留图片／音乐等本地引用路径，不包含资源文件、视频、登录态、API 配置或上传人；资源需另行提供并重新选择。本软件不支持直接导入参考工具的 `.cvp` 文件。

处理和校验在后台线程中串行执行。停止或关闭窗口会请求中止当前 FFmpeg，保留已完成成品和记录；失败项不会阻止后续素材。处理期间不接受导入成品或启动第二个加工任务。

### 当前支持

- 正式工作台默认“推荐 · 明显变化”：720×1280 模糊背景、前景占比 80% 且偏上、亮度 +0.02、对比度 1.12、饱和度 1.18、锐化 0.4、去头尾各 0.3 秒、1.06 倍速、30 fps。保留原声，不镜像、不裁边、不抽帧、不添加文案，以整体构图和调色形成差异；仍应先预览对白和字幕。
- 点击“收藏当前…”自行命名（1–40 字），保存九类创新参数；从收藏下拉框选中即应用。重启后收藏保留，同名覆盖和删除均需确认。“恢复推荐”只恢复内置参数，不改视频列表。旧版收藏补入新能力的关闭状态，不重置原参数。收藏不保存上传人、生成数量或预览片段；图片和配乐保留本地引用，移动文件后需要重新选择。
- 方案交换：导出当前参数为具名 JSON，导入前显示同名及缺失引用文件／资源池。默认为冲突项添加“（导入）”与编号，名称保持 40 字以内；取消、文件损坏或保存失败不修改原收藏及当前参数。一次最多导入 100 个方案，文件上限 2 MB，拒绝重复 JSON 字段、未知参数、错误版本及网络路径；不会下载或执行引用文件。导出不能覆盖本机收藏库。
- 画面：720×1280、1080×1920、1280×720、1920×1080 四种预设及自定义偶数宽高（240–3840）；模糊或黑边背景；前景等比缩放，可调整占比及上下位置；水平镜像、90/180/270 度旋转、四周等比例裁边。默认不镜像、不旋转、不裁边；主动裁边可能切到字幕，应先预览。
- 独立裁剪：画面页可选“上下左右独立”，各边按原片百分比输入，至少保留原片宽高各 5%；也可在原片上拖框选择保留画面。独立裁剪在手动旋转／镜像之前进行；旧“四周统一”裁边仍按原先变换顺序执行，两个模式不叠加，未选模式的参数保留。
- 分屏：上下两屏／三屏、左右两屏／三屏、四宫格；原片区域处理、裁剪／旋转后先排布，再应用画布背景与前景占比，不对已补黑边的画布重复缩小。单格可完整显示补黑边或铺满裁边；分屏不重复音轨、不改变时长。尺寸不能整除时单格保持偶数像素，外侧补齐到精确输出尺寸。分屏可能缩小画面原字幕，铺满会裁边，需先预览。
- 画面效果：原色、黑白、底片反色、复古棕褐；暗角 0–100%；0–40 像素外框与六位色值，0 关闭。风格／暗角作用于合成主体画布，边框向内绘制，叠片、新文字及水印在其上方，不作用于片头尾和封面。默认全部关闭，接入收藏和首版预览参数复用。
- 调色：可调亮度、对比度、饱和度，独立锐化、降噪；关闭调色时不应用前三项，锐化和降噪分别控制。
- 时间：去头尾、0.8–1.2 倍变速且保持音高；跟随原片或固定 24/25/30/50/60 fps；可选每 N 帧去掉一帧（N=2–300）。抽帧保留时间轴并由相邻帧补齐，不删除剧情时间段。
- 文字：保留原有全程快捷文字（最多 40 字）；“多文字轨”可额外添加最多 6 条，每条最多 160 字、3 行，独立设置字体、颜色、字号、位置／比例坐标、不透明度、黑色描边／阴影、底条、开始与持续时间，以及四方向滚动、速度和循环。支持 `{剧名}` 与 `{文件名}`；预览和正式生成使用同一来源上下文替换。字体提供默认中文／黑体／宋体，系统缺少对应字体时回退默认字体。固定文字自动适配宽度，滚动文字保持设置字号；需预览确认可读性。
- 水印：PNG/JPG/WebP 图片水印的位置、宽度占比、透明度、开始时间、持续时间、四方向循环滚动及速度。文字轨与水印的时间均从主体（裁剪／变速后）0 秒起算，持续为 0 表示到片尾；非片头预览保持正式时间轴相位。
- 字幕：导入本地 SRT／ASS，支持 UTF-8、GB18030、UTF-16；时间轴可对应原片（自动跟随裁剪／变速）或加工后主体，另可整体提前／延后最多 300 秒。SRT 可设置字号、六位颜色、黑色描边、上下边距与顶部／底部居中；ASS 可保留原字体和排版，也可统一样式。只烧录在主体，不覆盖原有画面字幕，不自动识别语音；复杂 ASS 动画经裁剪／变速后应专门预览确认。
- 封面：本地 PNG/JPG/WebP 图片或原片指定时间取帧，完整显示补黑边／裁切铺满。替换最终成片开头 0.1–3 秒画面（含片头），不增加时长、不移动声音；中途预览不重复封面。另存同名 `.cover.png`，路径写入成品媒体记录，原片及原图不修改；不会自动设置平台独立封面字段。
- 音频：保留原声、静音、混入背景音乐或仅背景音乐；独立原声／音乐音量。音乐可设置延迟、持续时间、淡入与淡出，短音乐循环；持续为 0 表示从延迟起到主体结束。预览按正式时间轴同步音乐素材偏移与音量包络。仅背景音乐会去掉主体对白，音乐时段外保留静音音轨；测试音轨不能当作正式配乐。
- 区域：旧单区保留原先“旋转、裁边后前景”的坐标含义；新增“原片多区域框选”，最多 6 处，分别设置启用、模糊／黑色遮挡／区域修补、坐标、模糊强度、主体开始与持续时间。新区域基于原片可视画面，先处理区域再独立裁剪、手动镜像和旋转，不作用于独立叠片或片头尾；旧单区如启用仍叠加，需用户自行关闭不需要的旧设置。
- 框选编辑器使用第一条勾选视频（无勾选时使用当前行），后台读取指定原片时间的截图；在等比显示区域内拖框，黑边不参与坐标换算。支持新增、选中后重新框选、移除区域，以及“保留全画面”；保存只更新区域／裁剪，取消保留原参数。读取中关闭会先停止截图任务再退出，不销毁运行中的线程。
- 区域修补采用 FFmpeg `delogo` 插值，不恢复被遮挡细节；区域不能贴边且实际宽高至少 4 像素，否则明确报错，贴边可选模糊或遮挡。原片带 90／270 度显示旋转信息时按实际显示尺寸换算，`probe` 的原宽高字段不改变，新增 `display_width`／`display_height`。
- 动态缩放（画面页）：缓慢推近、缓慢拉远、往返呼吸；幅度 0–25%，时长／周期 1–60 秒。作用于合成后的主画布，文字、水印与画中画不随主画布缩放；放大可能裁去边缘，需预览检查字幕。关闭为原有固定构图。
- 叠加：自定义 PNG/JPG/WebP 背景或 MP4/MOV/MKV/WebM/M4V 视频背景，铺满画布；另可叠加一张图或一路视频，等比缩放、百分比水平／垂直位置、透明度。短辅助视频循环，辅助视频声音不混入。留空背景仍使用原有模糊／黑边。
- 头尾：同样支持图片或视频，每段使用长度 0.5–30 秒；图片定格停留，视频只取前段，不足时按实际长度。统一为主体输出尺寸、帧率与方形像素，等比补黑边。可保留片头尾原声；图片／无声视频自动配静音，主体选择“静音”时全部成片静音。主体文字、水印、画中画和配乐不叠加到片头尾。
- 连接方式：直接拼接、交叉淡化、溶解、向左／向右擦除、向上滑动；转场时长 0.1–2 秒且不能超过最短片段一半，过长时明确报错，不静默更改。非直接拼接时音轨同步交叉淡化。最终时长为各段之和减去接点重叠；码率／文件大小预算使用该最终时长，最后完整解码并重新检查上传约束。
- 默认组合：背景变化、去头尾与变速、画面调色，分别对应背景、时长、风格三类。自定义关闭操作后不自动宣称符合需求方的“三类”验收。
- 多版本：未启用随机时，沿用不同调色强度；关闭调色时此模式只生成单版。启用随机后，可分别勾选前景占比、速度、亮度、饱和度、对比度、垂直位置、动态幅度的上下限，也可指定背景／叠片／水印／音乐／片头／片尾资源池文件夹；只枚举本层支持格式，不递归。音乐池需启用混音或音乐替换；调色及动态范围也须启用对应功能。
- 同一随机种子、来源绝对路径和版本序号可复现取值，资源池按路径排序后选择；“换一组参数”改变种子。无需启用调色即可通过构图和速度生成多版。每份成品保存实际 `options` 和原始 `requested_options`，不能仅靠数量或不同文件名判断视觉有差异。
- 随机预览展示第 1 版实际占比、速度与种子。设置未变化时，本次工作区记住第 1 版实际参数与资源，并在正式生成时复用；改变参数后旧预览不再复用。更换上传人或份数不改变预览方案。非片头预览的运镜相位、背景／叠片视频及配乐偏移按正式时间轴处理。预览起点及长度移至参数区底部，避免小屏常驻配置占满设置区。
- 改 MD5：重新封装并设置独立元数据，音视频不重新编码；校验新旧 MD5 不同。不会改变原片的码率与尺寸，不保证平台将内容认定为新素材。
- 微创新复用现有上传转码约束：视频码率超过 3500 且不超过 5000 kbps，文件不超过 522240 KB（510 MiB）。按处理后时长计算预算，无法满足时明确失败。
- 原文件不覆盖，成品按剧名分文件夹。记录来源 ID、路径、新旧 MD5、选项、版本、输出媒体信息和失败原因。
- 成品不标记为检测通过，不继承原片的检测结论。上传沿用现有未检测本地素材的使用约定，界面明确提示尚未检测。复杂内容判断目前由用户人工完成。

批次位置：素材保存根目录下的 `素材再创作/批次编号/`，其中 `recreation.json` 保存剧目、来源及成品列表。加工输出为 `加工成品/运行编号/剧名/微创新或改md5/`；每轮有 `manifest.json`。样片也保存在成品列表，关闭加工窗口不会丢失已完成记录。独立记住最近再创作批次，可从“历史批次”打开其他批次；不改变原任务的最近批次设置。

命名：`APP-繁花-王俨-微创新或改md5-剧名-上传人缩写-日期-序号.mp4`。生成后的平台暂存命名保留对应处理类型，不改变已有非加工素材的命名规则。

```python
def select_clips(video_path: str, metadata: dict, instruction: str) -> list[dict]:
    # start/end 单位为秒，坐标基于原视频，左闭右开。
```
