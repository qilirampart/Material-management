# 桌面 UI v0.2.0

按四张参考图改造了原生 PySide6 软件：深青导航栏、浅色工作区、白色分组面板、青绿主按钮。实际截图位于 output/desktop_smoke。

## 已接好

- 素材任务：Excel、分享链接、本地视频加入候选区，默认不勾选；勾选后执行仅下载、仅检测或下载并检测。重复输入去重；非法表格行保留并标注。每次导入可追加当前批次，也可新建批次。
- 执行范围为当前筛选中可见的勾选项。清空勾选清除所有勾选。仅检测缺少本地文件时标记待复核，不补下载；相同视频仅下载保留已有检测结果。
- 检测复核：素材列表、播放器、三帧证据、命中描边、原始识别文字、人工备注和重检。
- 平台工作台：可输入地址的内置浏览器和本机 profile；上传准备区为禁用占位。
- 设置：新增、删除、导入、编辑模型配置，密钥遮挡，后台图片请求测试；配置保存到本项目 runtime/model_profiles.json，不修改参考项目配置。保存目录、规则、参考图、解析参数、平台地址和恢复批次开关可编辑。

## 当前边界

- GitHub 更新源尚未发布，“检查更新”反馈待接入，不能下载或安装更新。保留配置升级方案见《桌面页面与保留配置更新设计》。本次未改变用户数据目录或迁移旧配置。
- 自动上传尚未实现。浏览器会话保留不代表平台永不要求重新登录。
- 下载检测在独立进程中串行排队，真实并发上限为 1；未实现参考图中同时执行 2 条的调度。大表读取和模型测试移到后台线程；表格复用已有单元格，结果 Excel 改为每轮结束或暂停时生成，JSON 进度持续保存。
- 首期侧栏证据为所选素材首帧预览；完整三帧在复核页。小于 1250px 的窗口收起任务侧栏，设置页可滚动。
- 片头未发现仅表示三帧抽检结果，不代表整段视频无命中。

## 验证

- 21 项单元测试通过，含仅检测不会下载缺失文件、短链接去重与域名限制。
- scripts/smoke_desktop.py：200 行、搜索、真实视频播放、三帧、备注、拦截、结果导出、页面切换、后台暂停通过。
- scripts/verify_ui_v2.py：默认不选、复选框、隐藏选择不执行、输入去重、三模式与模型配置保存重读通过。后台等待时 UI 心跳 34 次，最大间隔 22ms（局部响应测试，不是下载压力测试）。

安装包版本 0.2.0，安装标识和安装路径保持原项目设置；安装覆盖程序文件，不主动清理 runtime 或用户素材。在线更新器另行实现。
