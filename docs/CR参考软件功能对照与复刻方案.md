### 两个容易误解的名称

1. **去水印不等于恢复原画面。** 程序中可见 `delogo=x=...:y=...:w=...:h=...` 模板及平台区域 INI；这是区域修补路径的证据，未发现它证明可恢复被遮挡细节的依据。我们可增加区域修补，但不能叫 AI 无痕还原。
2. **场景检测不等于精彩剧情筛选。** 参考的场景分割阈值和最短时长用于切镜头；它不能据此理解剧情。仍按用户已确定的方向，精彩内容由人工选择或后续专门模型 API 完成。

## 建议按三层推进

### 第一层：最值得先补，明显改善成片差异

1. **动态构图**：慢推近、拉远、往返缩放、可控幅度与周期；上下左右独立裁剪与预览框选。
2. **背景／画中画／相框**：自定义图片或视频背景、前景叠片、PNG 相框、位置／比例／透明度；先做单资源，随后接资源池。
3. **多文字轨**：自由位置、字体／颜色／描边、时间控制、剧名及文件名变量、滚动与逐行显示。
4. **音乐与水印时间控制**：淡入淡出、延迟、持续时间、循环；图片／动图素材池。
5. **片头片尾与基本转场**：用户选择已授权素材；先支持简单淡入淡出，再扩展已选转场。
6. **真正的多版本方案**：数值可选固定值或范围，资源可选单文件或文件夹；记录随机种子、实际取值及资源。允许只变构图／音乐等而不强制启用调色。

推荐先落地 **1、2、6**：它们比增加十个轻微滤镜更能改变视觉效果，也符合批量处理需求。

### 第二层：接近常用编辑工具覆盖面

多区域与时段修补、更多画面效果、任意片段截取／拼接、封面设计、字幕烧录、画面分屏、音轨配对、收藏方案导入导出及引用素材缺失提示。

### 第三层：高级／独立工具

场景切分、转场重组、分段变速、静音段建议、定帧／倒放、图转视频、GIF、章节进度条。提供明确样片和人工确认；不让这些能力默认重排剧情。

## 实施时沿用的契约

- 五步流程不变；微创新设置仍是分类面板，复杂片段操作才展开时间轴。普通用户用收藏，熟练用户调高级参数。
- 使用组合效果与资源引用扩展处理契约；版本化保存方案，兼容现有收藏和历史成品参数，不通过改写旧字段的含义来兼容。
- 预览与正式生成使用相同的效果参数；多版本先固定一份实际随机结果再预览，用户认可后不能在正式生成时又随机一套。
- 片头尾、分段变速、配乐、抽帧、合屏都需重新计算视频和音轨时长，防止音画错位。
- 所有上传成品继续校验视频码率 >3500 且 ≤5000 kbps、文件 ≤510 MiB；新功能不能绕过最终校验。
- 保留原片和来源剧目；用户未主动选择时不混剧、不替换对白、不重排剧情。精彩内容筛选继续走人工／预留模型接口路线。
- 新能力均需真实 FFmpeg 输出、解码与音轨检查、UI 操作和小屏／大屏预览验收后再发布。本轮仅分析，未新增加工能力或构建发布。
