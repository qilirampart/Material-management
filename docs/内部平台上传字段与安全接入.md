# 内部平台上传字段与安全接入

来源：`繁花素材下载&上传.md` 及 2026-09-07 提供的 `market.wuread.cn/market-admin/` 页面截图。当前只做页面分析和字段契约，未提交任何真实素材，也未执行网站上传。

## 已确认字段

上传页面固定值：

- 类型：视频
- 性质一级：原创
- 需求方：张雯燕
- 素材类别：短剧
- 投放内容：短剧
- 产品：不限
- 免费付费：付费
- 可见部门：按规则文件中的部门全集

上传人和素材相关字段需要从页面登录状态或用户明确选择得到，不能由普通文本字段伪造。当前自由选择字段为编导、建议书籍/短剧；建议书籍/短剧必须同时保存平台 ID 和剧名，允许同剧多个 ID。

## 命名规则

规则格式：`APP-繁花-王俨-改md5-情报台-剧名-上传人缩写-YYYYMMDD-序号`。

黑体部分属于自由选择。日期使用四位年份；单次选择素材最多 50 条。命名器落地时需要处理 Windows 文件名非法字符、长度限制、序号补零策略和重名冲突，并在上传前显示最终名称预览。

## 后续上传流程

1. 选择下载和片头检测都已完成、没有命中、没有待复核状态的素材。
2. 显示固定字段、上传人字段、剧目映射和最终文件名，逐条显示字段来源。
3. 用户确认批次（最多 50 条）后，先在浏览器页面完成一次小批量手动验证。
4. 记录网站返回的素材 ID 或可核验结果；超时先查询结果，不盲目重复提交。
5. 上传状态独立于下载和检测，保存未加入、待上传、上传中、成功、失败、结果待确认。

## 浏览器接入边界

软件可以使用 Qt WebEngine 的持久化 profile，要求用户在软件内自行打开页面并扫码登录；登录会话只保存在该 profile。也可以在用户主动开启 Edge 远程调试后，通过 CDP 读取 DOM、字段、按钮和页面状态。

不读取、不导出、不打印 Cookie、Local Storage 中的令牌、扫码凭证、密码或 Authorization header；不从 Edge 用户目录复制登录数据。若 CDP 未连接，软件应明确提示用户开启远程调试或在内置浏览器登录。

页面探测阶段只读取：字段标签、选择项、文件 input、分页/上传按钮、必填校验提示、提交后返回的业务 ID。先通过 DOM 和截图确认页面结构，再决定是否需要辅助上传；不把页面截图中的水印、账号头像或个人信息写入日志。

## 当前截图观察

页面包含素材管理列表和“上传素材”表单。上传表单左侧为类型、性质一级、需求方、编导、素材类别、投放内容、建议书籍/短剧、产品；右侧为文件选择、可见范围、可见部门、可见截止日期、建议拉起章节。列表页已有“上传素材”“批量修改”“检测内容”“查看源文件”“全选”等入口。

这些观察来自用户截图，不等于已经验证 DOM selector 或后端接口。下一步需要在用户主动开放的 Edge CDP 会话中只读探测真实控件，再建立可维护的 selector 映射。
