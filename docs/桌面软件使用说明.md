# 点众素材投放助手 0.1.0

这是原生 Windows 桌面软件，主界面使用 PySide6。下载、检测、播放与证据复核均在本机完成；图片帧会发送给用户配置的识别模型。公司网站仅出现在“平台工作台”的内置浏览器中。

## 启动

免安装版：运行 `release/素材投放助手/素材投放助手.exe`。整个文件夹需一起保留，不能只复制 exe，`_internal` 中包含 Qt、Python 和 FFmpeg 运行库。使用免安装版无需另装 Python 或 FFmpeg。

安装版：运行 `release/素材投放助手-安装包-0.1.0.exe`，默认安装到当前用户的本地程序目录，可创建桌面快捷方式。

源码运行：双击 `启动素材投放助手.bat` 或执行 `python main.py`。

## 首次配置

设置 → 选择“语言模型配置文件”。当前默认指向你指定的 YouTube 字幕核验助手 `runtime/api_config.json`，选择其中启用的模型。抖音解析及下载参数默认只读引用原侵权巡检助手项目。

发布包不含 API 密钥。在其他电脑使用时，需要准备可用的配置文件并在设置中指定。模型配置文件需要包含 `llm.profiles`，各配置含 `id`、`enabled`、`api_base`、`api_key`、`model` 字段。

保存目录、禁用表达和 logo 参考图片可在设置中调整。logo 原图随软件分发。抽帧固定为首帧、1秒、2秒，短视频自动调整取点。

## 下载与检测

1. 点击“导入 Excel”，选择需求表；软件建立批次并复制输入表，保留原件。
2. 检查导入记录和异常行，点击“继续下载并检测”。“只下载”模式不调用模型，结果明确标为待复核/未检测。
3. 运行时可切换页面。点击暂停后，当前素材处理完成并保存，再停止下一条；继续时复用完成结果。
4. 可按状态筛选、按剧名或视频ID查询。双击素材打开复核；Ctrl/Shift 可多选后重新检测。
5. “重试失败 / 待复核”只处理相关条目。“导出结果”写出当前批次的 `复核结果.xlsx`，包含人工备注与人工拦截。

“打开历史批次”选择批次目录中的 `results.json`。新版本导入的批次包含 `input.xlsx`，可恢复运行。软件会记住最近打开的批次。

## 复核

显示本地播放器、三张证据帧、实际时间和模型转录文字。点击缩略图放大，点击时间定位播放器。人工备注另存于 `reviews.json`，不会覆盖原模型响应。

“人工确认拦截”要求填写理由。拦截记录保留视频、证据和原自动结论，不进入未来上传候选。此版本不提供人工一键放行。

检测规则修改后，旧的无命中结果显示为“规则已更新，需重检”；导出时也会列为待复核。

## 平台工作台

设置中填写实际公司站点的 HTTP/HTTPS 地址后，点击“打开平台”，用户可在内置浏览器中手动登录和浏览。网页登录使用独立的本机会话目录，不读取日常 Chrome 的登录信息。

本版本没有对接目标网站的账号识别、字段映射与自动上传。即使网页加载成功，也只显示“页面已加载 · 登录账号尚未自动识别”。站点的扫码、单点登录、弹窗和上传兼容性需要拿到实际网站后验证。

## 数据位置与退出

- 默认在程序目录下的 `runtime/` 保存本机设置、任务事件和浏览器会话。
- 默认在程序目录下的 `output/` 保存素材批次，可在设置中更换保存目录。
- 程序运行中退出，会询问是否等待当前素材处理完成后保存并关闭。不会直接终止正在写入的文件。
- 同一个批次不能在两个桌面窗口同时执行。

任务异常时，查看状态栏和批次结果原因；`runtime/job-*.events.jsonl` 保存阶段事件。更换电脑或交接时不要分享本机浏览器会话或包含密钥的配置。
