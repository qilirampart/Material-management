生成一张高保真 Windows 原生桌面软件 UI 设计参考图，横向 16:10，清晰可读简体中文，精致务实、可以用 PySide6 实现。不是网站、不是浏览器页面，无浏览器地址栏，无电脑实物或透视。画面几乎完全由一个桌面应用窗口占满，顶部真实 Windows 标题栏“点众 · 素材投放助手”及最小化最大化关闭按钮。视觉参考同公司字幕核验助手：左侧窄深青色 #103E46 导航栏，白色文字，选中项 #1A6E70；右侧浅灰 #F4F6F8 工作区，白色分组面板、细边线、8px圆角，主按钮青绿 #0F766E。微软雅黑风格中文，无夸张渐变和装饰。
这是产品概念图，所有数据为示例。主视图占80%宽度，右边20%宽度为当前任务/证据预览栏。
左侧导航品牌“点众 / 素材投放助手”，菜单“素材任务”（选中）、“检测复核”、“平台工作台”（旁边小字“待接入”）、底部“设置”。
主工作区顶部标题“素材任务”，小字“导入素材，勾选后开始处理”。右上“历史批次”。
第一白色卡片“添加素材”，有三个清楚的入口按钮“导入 Excel”“粘贴抖音链接”“添加本地视频”。下面一行简洁摘要“当前批次：婚房门后的秘密 · 200 条素材”。粘贴链接表现为可输入分享文字的单行输入框+“加入候选区”按钮。导入仅加入候选区，不自动执行。
第二白色主卡片标题“候选素材”，右侧搜索框“搜索剧名 / 视频 ID”。标题下一行“全选当前”“清空勾选”“已勾选 3 条”；右边用紧凑分段控件三选一“仅下载 | 仅检测 | 下载并检测”（第三项选中），主要操作按钮“处理勾选的 3 条”。
主体是一张专业密度的数据表，每行左侧独立复选框，列头“选择 / 素材 / 来源 / 下载状态 / 检测状态 / 命中内容”。7行，同一剧名“婚房门后的秘密”配小灰短ID。第1-3行已勾选，其余未勾选。状态示例：下载中 64%细进度条、等待处理、已下载+片头未发现、已下载+命中拦截（暖红标签）+“免费看”、本地视频+待检测、已下载+待复核。不要把未检测显示通过。
右侧栏白色卡片“后台任务”，显示“运行中 2 / 并发上限 2”，两条任务进度，“暂停队列”次按钮，下面小字“暂停后等待当前任务结束”。下一白色卡片“片头证据”，三张小竖版短剧人物画面缩略图，标签“首帧 0.0s”“1.0s”“2.0s”，命中的一张暖红描边，下面“命中文字：免费看”和“查看证据”。下方轻灰说明“仅抽检片头三帧，不代表全片审核通过”。
底部状态栏“模型：qwen3-vl-flash · 可配置”带“模型设置”文本按钮；右侧“保存到本地 · 平台上传待接入”。
在主窗下方或右下角合理叠放一个小型但清晰的原生对话框，标题“图片识别模型”，有“配置名称”“API 地址”“模型名称”“API Key”四个表单字段，值“通义视觉”“https://…/compatible-mode/v1”“qwen3-vl-flash”“••••••••••••”；底部“测试连接”“保存配置”。对话框不要遮挡表格选择操作和三模式控件。画面整洁统一、控件真实、文字准确，不出现网站营销标题。
